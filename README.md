# FastoPay - Responsive Landing Page

A modern, responsive landing page for FastoPay - a global payment processing platform.

## Features

- **Responsive Design**: Fully responsive layout that works on all device sizes
- **Modern UI**: Clean, professional design with smooth animations
- **Scroll Animations**: Engaging scroll-triggered animations for better user experience
- **Hero Section**: Eye-catching hero with call-to-action buttons
- **Features Grid**: Showcase of key platform features
- **Trust Bar**: Statistics and social proof section
- **Navigation**: Responsive navigation with mobile menu support

## Technologies Used

- HTML5
- CSS3 (with custom animations)
- Font Awesome (icons)
- Google Fonts (Inter)
- Vanilla JavaScript (for mobile menu toggle)

## File Structure

```
Responsive_design/
├── index.html      # Main HTML file
├── styles.css      # Custom stylesheet
├── hero.png        # Hero section image
└── README.md       # Project documentation
```

## How to Use

1. Clone or download this repository
2. Open `index.html` in a web browser
3. No build process or dependencies required - it's a static website

## Customization

- **Colors**: Modify CSS variables in `styles.css`
- **Content**: Edit text in `index.html`
- **Images**: Replace `hero.png` with your own image
- **Animations**: Adjust animation timings in the `<style>` section of `index.html`

## Browser Support

- Modern browsers (Chrome, Firefox, Safari, Edge)
- Fallback animations for older browsers
- Mobile-friendly design
